# Лучшая учебная группа

Официальный сайт конкурса «Лучшая учебная группа» МГТУ им. Н. Э. Баумана. Публичные разделы собраны на HTML/CSS и браузерном JavaScript; регистрация, личный кабинет, портфолио, уведомления и административные решения работают через FastAPI backend из [`backend/`](backend/README.md).

## Полный локальный запуск

Для запуска полного стека нужен Docker Desktop с запущенным Docker Engine. Единый `docker-compose.yml` в корне собирает сайт и API, запускает PostgreSQL, Redis, MinIO, ClamAV и Mailpit. Один раз скопируйте шаблон локального окружения:

~~~powershell
Copy-Item .env.example .env
~~~

Проверьте `LUG_ADMIN_EMAIL` и задайте свой пароль в `.env`, затем поднимите весь проект из корня:

~~~powershell
docker compose up --build -d
~~~

Сайт откроется на [http://127.0.0.1:4173/](http://127.0.0.1:4173/); API — на `http://127.0.0.1:4174/`; Mailpit — на [http://127.0.0.1:8025/](http://127.0.0.1:8025/). Сайт проксирует API-запросы по внутренней Docker-сети. Порты MinIO не публикуются на хост. Посмотреть логи можно командой `docker compose logs -f web backend`. `docker compose down` останавливает контейнеры и сохраняет volumes.

Если Docker недоступен, frontend и backend можно запускать отдельно для разработки: установите Node.js и Python 3.11+, скопируйте `backend/.env.example` в `backend/.env`, задайте параметры dev-режима, затем запустите `npm run backend:dev` и `npm run start` в двух терминалах. Этот режим использует SQLite.

Учётная запись первого администратора задаётся переменными `LUG_ADMIN_EMAIL` и `LUG_ADMIN_PASSWORD` в игнорируемом Git файле `.env` в корне. Шаблон `.env.example` предназначен только для разработки: поменяйте пароль перед запуском и не публикуйте `.env`.

В Compose-режиме письма восстановления пароля открываются в локальном Mailpit. Команда `docker compose down --volumes` удаляет локальные базы и файлы.

## Кабинет и админ-панель

- Участник может редактировать профиль, следить за статусом документов, управлять командой и ссылкой-приглашением, отправлять видео и достижения, читать уведомления и завершать другие сессии.
- Регистрация капитана и вступление по приглашению сразу создают аккаунт и сессию; подтверждение почты не требуется. Сервер проверяет приглашение и приватную загрузку студенческого билета.
- Организатор получает сводку, проверяет команды, состав, личности, достижения и видео, настраивает сроки конкурса, отправляет объявления и просматривает журнал действий.
- Роли и права проверяются backend; клиент не хранит пароль или роль в `localStorage`.

## Сборка и структура

~~~text
index.html                    # публичная страница и точка входа кабинета
src/components/                # шапка, меню и окно авторизации/регистрации
src/sections/                  # публичные разделы сайта
src/account/                    # перенесённые кабинет участника и панель организатора
src/scripts/features/account/   # API-клиент и модули кабинета, админки и регистрации
src/styles/auth-dialog.css      # окно авторизации и многошаговой регистрации
scripts/                       # сборщик и локальный сервер с API proxy
Dockerfile                     # многоэтапная сборка frontend контейнера
docker-compose.yml             # полный стек сайта, API и инфраструктуры
backend/                       # FastAPI modular monolith в этом репозитории
dist/                          # результат сборки, не редактировать вручную
~~~

Отдельная сборка сайта: `npm run build`. Подробности находятся в [локальном запуске](docs/getting-started.md), [архитектуре](docs/architecture.md) и [конфигурации](docs/configuration.md). API контракты и серверные операции описаны в [backend README](backend/README.md).

Кабинет, панель организатора и сценарии регистрации перенесены из [`artemnoor/lug-2026`](https://github.com/artemnoor/lug-2026); главная страница и публичная дизайн-система остаются исходными для этого проекта. Публичная палитра применяется к кабинетным экранам через локальные CSS-токены.
