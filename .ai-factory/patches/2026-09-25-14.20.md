# Страница раскрывалась до загрузки Webflow CSS

**Дата:** 2026-09-25 14:20 (Europe/Moscow)
**Файлы:** `index.html`, `tests/e2e/visibility.spec.js`, `docs/architecture.md`
**Серьёзность:** высокая

## Проблема

При холодной перезагрузке содержимое страницы могло кратко появиться без оформления, а затем часть блоков исчезала. Если stylesheet с CDN долго не отвечал, таймер видимости снимал fallback, хотя стили ещё не были готовы.

## Первопричина

Внешний stylesheet загружался асинхронно, а reveal-watchdog раскрывал DOM независимо от его состояния. Запрос CSS мог оставаться ожидающим, поэтому браузер показывал HTML до стилей либо оставлял страницу в неопределённом состоянии.

## Решение

- Пока базовый stylesheet ожидается, `.transition-container` скрыт, прелоадер остаётся видимым.
- После успешной загрузки stylesheet применяется через `media="all"`, и страница раскрывается.
- При ошибке или ожидании дольше 12 секунд отображается сообщение; поздний ответ stylesheet восстанавливает обычный показ.
- Bootstrap не снимает прелоадер раньше готовности базовых стилей.

## Предотвращение

- Проверять холодную загрузку с задержкой, ошибкой и зависшим ответом stylesheet.
- Проверять успешный ответ после задержки: контент остаётся закрытым до CSS и становится видимым после загрузки.
- Не считать reveal fallback заменой обязательному CSS.
