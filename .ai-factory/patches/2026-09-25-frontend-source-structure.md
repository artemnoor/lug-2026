# Исходники frontend разделены по компонентам и секциям

**Дата:** 2026-09-25
**Файлы:** `index.html`, `src/`, `scripts/build-site.mjs`, `scripts/serve-site.mjs`, `scripts/check-local-assets.mjs`, `tests/e2e/source-structure.spec.js`, документы проекта
**Основание:** явный запрос пользователя разложить монолитную страницу на поддерживаемую структуру папок

## Изменения

- Разметка шапки, оболочки, прелоадеров, модальных окон и девяти секций хранится отдельными HTML-фрагментами в `src/components/` и `src/sections/`.
- CSS вынесен в `src/styles/site.css`; браузерные скрипты разложены по `bootstrap/` и `features/`; изображения и шрифты собраны в `src/assets/`.
- Корневой `index.html` подключает HTML-фрагменты директивами `@include`.
- `npm run build` раскрывает шаблоны и копирует нужные браузеру файлы в игнорируемый `dist/`. `npm run start` автоматически собирает и отдаёт `dist/`.
- Стек сайта не менялся; сборщик использует стандартный Node.js и не добавляет frontend bundler.

## Проверка

- `npm run build` — успешно.
- `node scripts/check-local-assets.mjs --strict-unused` — 78 ссылок, отсутствующих и некорректных путей нет.
- `node --check` — 21 JavaScript-файл прошёл проверку синтаксиса.
- Playwright: структура/порядок секций и reveal callback — 2 теста пройдены; сценарии холодной загрузки CSS — 3 теста пройдены.
- Полный визуальный набор требует доступный Webflow stylesheet с CDN; в текущем окружении его запрос завершается ошибкой, поэтому проверки геометрии, зависящие от CDN, не подтверждены.
